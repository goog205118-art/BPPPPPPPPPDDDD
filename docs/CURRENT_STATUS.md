# 当前状态

## 更新时间

2026-08-24

## 当前结论

第一版 MVP 已完成本地落地测试，可以作为“达人与资源沉淀工作台”的可用原型继续试用。

线上 Vercel 版本的部署文件已准备完成：资料和 AI 设置会改存 Vercel Blob，网页由访问密码保护，不再依赖本地端口、VPN、Python 或 SQLite。

## 当前存储

- SQLite 数据库：`%TEMP%\ResourceWorkbench\resource-workbench.sqlite3`
- JSON 镜像：`%TEMP%\ResourceWorkbench\state.json`
- AI 设置：随 SQLite 数据库保存；旧版 `data/storage\ai-settings.json` 会自动迁移
- 邮箱 IMAP 设置：本地独立保存至 `%TEMP%\ResourceWorkbench\mail-settings.json`；授权码以 AES-256-GCM 加密保存
- 项目种子数据：`D:\编码\资源复用\resource-workbench\data\state.json`

## 当前数据量

数据以运行中的 SQLite 数据库为准。项目内 `data/state.json` 与 `data/storage/state.json` 曾存在历史镜像不同步，示例数据清理前不再在本文档中写死数量，避免误导。

## 已知边界

- Gemini AI 代理已接入，真实补全需要先在“设置”页配置 API Key，也可改用 `GEMINI_API_KEY` 或 `GOOGLE_API_KEY` 环境变量
- 重复合并已有基础规则，后续需要更细的去重策略
- Foxmail `.eml` 导入仍保留为备用；官邮同步走标准 IMAP，不读取 Foxmail 本地目录，也不保存原始邮件或附件
- 官邮同步当前只提供手动“立即同步”，不做定时任务；不同服务商的已发送文件夹名称需要在设置中按实际值填写
- 线上版使用 Vercel Function 连接邮箱服务器，是否可连通取决于邮箱服务商网络策略；正式使用前应先在设置页测试连接
- 当前为可双击启动的本地 Web 程序；若需要完全无命令窗口的桌面图标，可在下一阶段封装桌面壳
- 线上版面向单一负责人或小型可信团队，暂不适合多人同时编辑同一份资料
