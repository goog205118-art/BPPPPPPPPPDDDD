# 当前状态

## 更新时间

2026-08-31

## 当前结论

第一版 MVP 已完成线上与本地可用性测试，可以作为“达人与资源沉淀工作台”的可用原型继续试用。

线上 Vercel 版本已具备部署文件：资料和 AI 设置会改存 Vercel Blob，网页由访问密码保护，不再依赖本地端口、VPN、Python 或 SQLite。

- 只有在用户同时开启“缓存完整正文”和“授权 AI 使用正文”后，AI 才会读取当前品牌、当前合作跟进、未过期的最近 10 封正文；跨品牌、其他跟进、未授权与过期正文都不会进入模型上下文
- 合作跟进详情会显示 AI 实际可用的完整正文、摘要、缓存开关与授权范围，避免把摘要分析误认为完整线程分析
- 官邮邮件仅在唯一匹配“达人邮箱 + 活跃合作跟进”时自动写入时间线；未匹配、多人匹配或多条活跃跟进的邮件会保留在待人工归档区
- 邮件上下文按同品牌、同一合作跟进聚合；所有事件保留摘要，在约 48000 字符总预算内优先纳入最新的完整正文；单封正文仍受长度限制，附件、原始 MIME 和邮箱外沟通不可见
- 待人工归档邮件可从当前品牌达人库手动绑定已有达人；无活跃跟进时自动新建默认合作跟进并归档，只有一条活跃跟进时直接归档，多条活跃跟进时必须手动选择目标跟进
- 达人库与待开发达人均支持维护“最近首联 / 复联发件时间”；已发送邮件同步、系统发信、人工记录待回复和调起待开发邮件客户端都会回写该时间；调起客户端还会建立一条标注为人工联系意图的“已联系待回复”跟进，不伪造 `mail_sent`
- 若历史首发邮件漏同步为待回复轨迹，官邮回信仍可在唯一匹配同品牌达人且发件时间不超过 30 天时自动进入“初步沟通”；过期、共享邮箱或多人匹配仍保留人工确认
- 已有活跃合作跟进即使超过 30 天仍可继续按线程或联系轨迹关联；30 天限制只用于找回遗漏的首联 / 复联待回复轨迹；已转入达人库的旧待开发线索不再单独参与匹配
- 同一官方邮箱服务多个品牌时，邮件先按品牌范围和线程关联；仍存在多个候选品牌或多个活跃跟进时进入人工确认，不跨品牌自动归档

## 当前存储

- 本地 SQLite 数据库：`%TEMP%\ResourceWorkbench\resource-workbench.sqlite3`
- 本地 JSON 镜像：`%TEMP%\ResourceWorkbench\state.json`
- AI 设置：随 SQLite 数据库保存；旧版 `data/storage\ai-settings.json` 会自动迁移
- 邮箱 IMAP 设置：本地独立保存至 `%TEMP%\ResourceWorkbench\mail-settings.json`；授权码以 AES-256-GCM 加密保存
- 项目种子数据：`D:\编码\资源复用\resource-workbench\data\state.json`
- 线上 Vercel 运行时：业务资料、AI 设置和邮箱设置由 Vercel Blob 保存；访问密码以 Vercel 环境变量保存

## 当前数据量

数据以运行中的 SQLite 数据库为准。项目内 `data/state.json` 与 `data/storage/state.json` 曾存在历史镜像不同步，示例数据清理前不再在本文档中写死数量，避免误导。

## 已知边界

- Gemini AI 代理已接入，真实补全需要先在“设置”页配置 API Key，也可改用 `GEMINI_API_KEY` 或 `GOOGLE_API_KEY` 环境变量
- 重复合并已有基础规则，后续需要更细的去重策略
- Foxmail `.eml` 导入仍保留为备用；官邮同步走标准 IMAP，不读取 Foxmail 本地目录，也不保存原始邮件或附件
- 官邮同步当前只提供手动“立即同步”，不做定时任务；不同服务商的已发送文件夹名称需要在设置中按实际值填写
- 线上版使用 Vercel Function 连接邮箱服务器，是否可连通取决于邮箱服务商网络策略；正式使用前应先在设置页测试连接
- 当前为可双击启动的本地 Web 程序；若需要完全无命令窗口的桌面图标，可在下一阶段封装桌面壳
- 线上版面向单一负责人或小型可信团队，暂不适合多人同时编辑同一份资料
- 多品牌隔离目前以 `brand_id` 为核心：同一达人在不同品牌下仍会各自保存一条资料，尚未升级为“全局唯一达人主档 + 品牌-达人关系”的数据模型
- 邮件正文缓存默认关闭；开启正文缓存和 AI 授权后，AI 可基于当前品牌、当前合作跟进、未过期的邮件摘要和完整纯文本正文研判。所有事件摘要会保留，完整正文受总上下文预算、单封长度和保留期限限制；摘要和旧截断正文会在后续同步到更完整内容时升级。附件、图片、原始 MIME、邮箱外沟通仍不可见
- AI 可以生成中文摘要、跟进建议和回复草稿，但尚未完成“待归档邮件 -> 人工绑定/新建合作项目 -> 选择策略 -> 生成并发送”的一体化邮件工作台
- 当前 AI 只提供建议与草稿，不会自动推进合作阶段；“已签收、已发布、数据回收”等高风险阶段仍需物流、链接或人工确认。用户确认应用 AI 建议后，页面会同步联系轨迹状态
- 尚未实现以合作项目为中心的统一 Case、任务编排和“今日推进”页面；定时同步邮箱与定时 AI 状态建议也尚未启用
