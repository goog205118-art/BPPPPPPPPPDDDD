# 资源沉淀工作台执行文档

## 目标

把“达人与资源沉淀”的手工表格，升级成一个本地可查、可筛、可导入导出的管理工具。

## 方案 A

方案 A 采用本地 Web 程序作为第一阶段载体，数据落地到本地文件和 SQLite，由程序负责增删改查、导入导出和筛选。第一版先保证本地可用、数据可保存、旧表可迁移，AI 能力放在第二阶段增强。

## 执行步骤

### 第 1 步：字段标准化

1. 统一达人字段
2. 统一资源字段
3. 统一合作记录字段
4. 所有多标签字段使用 `|` 分隔
5. 所有日期使用 `YYYY-MM-DD`

验收标准：

- 字段名固定
- 每条记录有唯一 ID
- 可直接导出 CSV

### 第 2 步：本地程序

1. 使用 Node 启动本地服务
2. 页面在浏览器中可直接操作
3. 前端负责筛选、搜索、编辑和展示
4. 后端负责保存到本地 SQLite

验收标准：

- 可启动
- 可保存
- 刷新后保留数据

### 第 3 步：三张核心表

1. `creators`
2. `resources`
3. `cooperations`

验收标准：

- 三张表可独立维护
- 每张表可筛选
- 每张表可导出 CSV

### 第 4 步：筛选规则

1. 关键词搜索
2. 下拉筛选
3. 按国家、状态、等级、合作方式等组合筛选

验收标准：

- 可快速找到指定达人或资源
- 不必在原始表格里逐格查找

### 第 5 步：智能辅助

1. 自动补标签
2. 自动补默认分级
3. 自动生成简单建议
4. 后续可接 AI API

验收标准：

- 保存时能看到建议
- 不接 AI 也能工作

### 第 6 步：导入旧表

1. 打开程序
2. 进入要导入的模块
3. 点击导入表格
4. 先看预览
5. 必要时手动调整字段映射
6. 点击确认导入
7. 程序按当前模块字段自动识别表头
8. 同名同平台达人或同名同类型资源会做更新

验收标准：

- 旧表可导入到当前模块
- 导入后可搜索和筛选
- 重复资源不会无限新增

### 第 7 步：第一版落地测试

1. 打开 `http://localhost:4173/`
2. 新增一条达人测试记录
3. 修改这条达人记录的状态
4. 删除这条达人记录
5. 导出达人 CSV
6. 导入一份 XLSX 测试表
7. 检查中文是否正常
8. 恢复种子数据

验收标准：

- 新增、编辑、删除均通过
- CSV 导出保留中文
- XLSX 导入保留中文
- 数据最终恢复到测试前状态

### 第 8 步：下一阶段增强

1. 修复导入按钮形态，确保文件导入控件和普通按钮视觉一致
2. 将左侧录入区改为紧凑双列，备注类字段独占整行
3. Excel 导入读取所有工作表，并在预览中提示来源工作表数量
4. 智能建议按当前表单内容生成可应用更新
5. 导入前预判新增、更新和文件内重复数量
6. 导入完成后记录历史，并支持回滚到导入前状态

验收标准：

- 导入 JSON 和导入表格按钮不再变形
- 首屏可显示更多录入字段
- 多 Sheet Excel 可一次解析并导入
- 智能建议可一键填入表单
- 确认导入前可看到重复风险
- 导入历史刷新后仍保留
- 可通过回滚恢复导入前数据

### 第 9 步：重复识别与合并

1. 在当前模块内自动识别疑似重复记录
2. 达人按同名同平台优先识别，资源按同名同类型优先识别，合作记录按达人、产品和日期识别
3. 同名但关键字段不同的记录先作为“疑似重复”提示，避免误合并
4. 合并时保留信息更完整、更新时间更近的记录
5. 标签、品类、内容类型和备注做去重合并，数字字段保留较高值
6. 不需要处理的疑似重复可先忽略

验收标准：

- 当前模块有重复时，列表上方显示疑似重复面板
- 可点击重复行进入编辑查看
- 可一键合并到建议保留项
- 合并后数据立即保存到 SQLite
- 可忽略暂不处理的疑似重复

### 第 10 步：达人 AI 补全与前台设置

1. 达人库新增社媒地址和达人邮箱字段
2. 新增“设置”页，可维护 API 地址、API Key、协议和模型名
3. 设置保存到本地 `ai-settings.json`，后端调用时读取，环境变量作为兜底
4. “从链接补全”按钮已集成到达人“社媒地址”行，取消下方单独补全框
5. 填写达人主页链接后，由本地后端调用 Gemini API
6. AI 仅补充可搜索或可验证的信息，未知字段保持空白
7. 前端只填充当前为空的字段，不覆盖人工已录入内容
8. 补全后由人工复核，再点击保存写入 SQLite

验收标准：

- 达人表单可录入社媒地址和达人邮箱
- 导入表格可识别“达人链接 / 主页链接 / 邮箱 / email”等表头
- 设置页可读取、保存并检查 AI 配置状态
- 未配置 API Key 时有明确提示，其他功能不受影响
- 配置 API Key 后可从达人社媒地址补全空字段
- 补全结果不会覆盖人工已填写字段

### 第 11 步：升级到桌面壳

1. 接入 Electron
2. 将当前页面封装为桌面程序
3. 保持本地文件存储不变

验收标准：

- 生成可双击的桌面程序
- 数据仍能本地保存
