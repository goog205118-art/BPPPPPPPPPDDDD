# 开发资源库

本项目是一个资源管理工作台，面向达人沉淀、Deal 资源管理和合作记录复盘，优先解决“表格逐个填写、查找和筛选麻烦”的问题。

当前同时保留两种运行方式：

- 本地版：Node + SQLite，适合离线使用。
- 线上版：Vercel Serverless + Vercel Blob，适合从浏览器访问，不依赖本地端口、VPN、Python 或 SQLite。

线上部署的完整操作见 [DEPLOY_VERCEL.md](DEPLOY_VERCEL.md)。

## 运行

```bash
npm start
```

然后打开：

```text
http://localhost:4173
```

Windows 下也可直接双击项目根目录的 `启动资源工作台.cmd`。服务就绪后，在浏览器打开 `http://localhost:4173`；保持命令窗口运行即可使用，关闭窗口会停止本地服务。

程序数据默认保存在 Windows 用户临时目录下的 `ResourceWorkbench` 文件夹，避免安全软件阻止本地服务写入项目文件夹。首次启动新版程序会自动迁移旧的 `data/storage` 数据、备份和 AI 设置。也可通过环境变量 `RESOURCE_WORKBENCH_STORAGE_DIR` 指定其他数据目录；需要长期归档时，请定期使用顶部“导出 JSON”备份。

## AI 补全配置

打开顶部“设置”页，可分别配置三套 AI 服务：达人库“从链接补全”用于补充完整资料；待开发达人“自动检索”仅整理名称、平台、国家、垂类、粉丝、近 30 条平均播放、互动率和可验证邮箱等核心字段；“达人开发邮件”可使用更适合英文写作的模型，根据所选达人、产品和当次规则生成开发草稿。三套配置都支持 Gemini 与 OpenAI 兼容协议，可分别填写 API 地址、API Key、模型名和可选 HTTP/HTTPS 代理地址。

AI 设置随本地 SQLite 数据库保存；旧版 `data/storage/ai-settings.json` 会在首次启动时自动迁移。

```text
%TEMP%\ResourceWorkbench\resource-workbench.sqlite3
```

未在设置页保存 API Key 时，程序仍可正常新增、保存、导入和导出；点击“从链接补全”会提示先配置 API Key。环境变量 `GEMINI_API_KEY` / `GOOGLE_API_KEY`、`GEMINI_MODEL` 和 `HTTPS_PROXY` / `HTTP_PROXY` 仍可作为兜底。若 API 域名被本地代理软件解析为 `198.18.x.x` 或 `198.19.x.x`，请在设置页填入该代理软件提供的 HTTP 代理地址。

线上版使用同一套设置界面，但 AI 请求由 Vercel 云端直接发出，因此不需要、也不支持用户电脑上的本地代理端口。线上 AI Key 保存在私有 Blob 文件中，保存后不会回显。

## 第一版功能

- 达人库，支持所属品牌归类和按品牌筛选
- 待开发达人：粘贴社媒地址后自动检索核心信息，可确认后转入达人库
- 产品库：按品牌、国家/地区、类目和店铺维护产品；可从公开产品链接读取名称、主图和简介
- AI 开发邮件：在待开发达人页单选或多选达人，选择产品与当次规则后生成可编辑英文草稿，并可复制或调起默认邮件客户端
- 达人社媒地址和达人邮箱录入
- 资源库，支持所属品牌归类和按品牌筛选
- 合作记录
- 本周资源匹配：按国家、品类、新品/清库存、预算、独家和上线周期推荐资源，保存待联系清单与执行结果
- 关键词搜索
- 条件筛选
- 新增、编辑、删除
- CSV / XLSX 表格导入
- 导入预览和字段映射
- JSON 导入 / 导出
- CSV 导出
- 本地 SQLite 持久化
- JSON 镜像备份
- 规则版智能建议占位
- Excel 多 Sheet 导入
- 紧凑双列录入表单
- 智能建议一键应用
- 导入前新增 / 更新 / 重复预判
- 导入历史和一键回滚
- 疑似重复识别与合并面板
- 前台 AI 参数设置页：达人完整补全、待开发快速录入和开发邮件可使用不同协议、地址、Key、模型与代理
- 达人社媒地址和邮箱双向去重，导入时也会跳过跨达人库 / 待开发库的重复资料
